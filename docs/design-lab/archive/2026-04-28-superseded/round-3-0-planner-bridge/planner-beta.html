Reading Mode

Why this plan works

Reading view is where the planner starts teaching. The same plan becomes a chapter-like explanation: bridge years are funded carefully, government income is delayed for protection, and withdrawals are smoothed to reduce future tax spikes.

Trajectory and interpretation

Builder view keeps the plot close to the controls so the user can test changes quickly.

Reading view turns the same plot into an interpretive stop: what matters is not just the line, but what the line says about durability and pressure.

The bridge behavior is not about hiding the chart. It is about pairing the chart with enough interpretation that the user can carry the lesson into the report later.
