# Baseline Validation Checklist

Use this checklist before and after extraction to ensure parity.

## Data setup (3 reference scenarios)

1. Solo profile (no spouse, no business)
2. Couple profile
3. Business-on profile

## For each scenario

1. Run simulation.
2. Open Tab 9 report preview.
3. Save HTML export.
4. Run Excel export.
5. Capture a screenshot of report header + KPI cards.

## Compare old vs new

1. Same section order.
2. Same KPI values and formatting.
3. Same key tables and totals.
4. Same language behavior (`fr`/`en`).
5. Same mode behavior (`standard`/`expert`).
6. Excel sheets present and populated.
7. No missing charts/blocks in report iframe.

## Pass criteria

1. No missing section.
2. No unexplained KPI delta.
3. No export runtime error.
