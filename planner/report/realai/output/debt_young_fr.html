Méthodologie SRG
Revenu compté dans le test : RRQ + pension d'employeur + retraits REER / FERR + revenu locatif net + dividendes imposables. Exclut : PSV elle-même, retraits CELI, prestations SRG reçues.
Pourquoi le total viager peut sembler élevé : il accumule sur 26 années après 65 ans en dollars constants de 2026. Une admissibilité partielle de 6–8 ans à 33K$/an cumule rapidement.
Récupération : chaque dollar de revenu compté réduit le SRG d'environ 50¢ (un peu plus pour certains paliers). Le seuil 2026 pour une personne seule est d'environ 22K$ de revenu compté — au-delà, l'admissibilité disparait.
