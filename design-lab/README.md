# BuildFi Design Lab

This folder is the working space for cross-product design system work.

Purpose:
- keep the portfolio roadmap in one place
- preserve UI/report experiments that should not live in production folders
- compare alternative shells without touching canonical report outputs
- document design decisions before they become implementation work

Structure:
- [ROADMAP.md](/C:/Users/tredh/OneDrive/Documents/GitHub/buildfi/design-lab/ROADMAP.md)
  Portfolio-level system plan.
- [notes](/C:/Users/tredh/OneDrive/Documents/GitHub/buildfi/design-lab/notes)
  Audits, decisions, and short design memos.
- [experiments](/C:/Users/tredh/OneDrive/Documents/GitHub/buildfi/design-lab/experiments)
  Self-contained prototypes and interaction tests.

Working rules:
- experiments live here first, not in `planner/report/realai/final`
- if a prototype is worth keeping, preserve both the HTML and the script here
- production files stay the source of truth unless an experiment is explicitly promoted
- each experiment folder should include a short `README.md`
