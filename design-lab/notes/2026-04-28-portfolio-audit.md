# Portfolio Audit — 2026-04-28

## Diagnosis
BuildFi currently has multiple visual dialects:
- marketing / debt / decum tool: cool slate-gold product style
- planner: warmer dark lab style
- guides: warm editorial style
- reports: refined editorial print style

## Most important friction
- the Next app shell loads one font system and visibly uses another
- palettes are duplicated inline instead of shared semantically
- the website does not yet fully feel like the same family as the tools it sells

## Strategic recommendation
Use two expressions, not three:
- Product
- Editorial

The website should align to Product.
Guides and reports should align to Editorial.

## Why this matters
Users should feel:
- continuity when they move from landing page to tool
- continuity when they move from guide to report
- one company, not several adjacent projects
