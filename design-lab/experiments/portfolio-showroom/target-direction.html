BuildFi Design Lab — Round 2

Target Direction

This board is the proposed future portfolio architecture. It does not assume one visual skin everywhere. It assumes one brand system, with a shared product language, a reading language, and a planner bridge that connects simulation to explanation.

Current showroom Roadmap Report toggle lab
Recommendation

One portfolio, three roles

Not three unrelated styles. Three coordinated roles inside one system: Product for tools and selling, Planner Bridge for simulation plus explanation, and Reading for guides and AI reports.

Website evolves, not flips The website should align to Product, but with more warmth and persuasion than the raw tools.
Planner is the hinge It should not be trapped in old laboratoire styling. It should be the bridge between tool mode and report mode.
Guides and reports align naturally They already want to be a publication system.
Shared system underneath Same tokens, same numbers, same spacing/radius/shadow logic, same dark/light persistence.
Round 1 conclusion

Start where the coherence win is highest and the risk is lowest: tools, guides, reports, and planner alignment. Leave the website as a lighter evolution in the first pass.

Future Role

Planner Bridge

The planner is not just another tool page. It is where BuildFi moves from simulation to explanation, and from data entry to report trust.

Planner bridge

Simulate, then understand.

This is where the V3 final toggler / hybrid reading view matters. The planner should keep product-grade controls, but gain a calmer explanation layer.

Future Role

Reading

Guides and AI reports. Warm, chaptered, print-friendly, and calmer than the tool layer, while still clearly part of BuildFi.

Reading language

Calm, premium, linear.

This is where users learn, review, and reflect. It should feel composed, chaptered, and credible, not like an app export.

Recommended Next Moves

What should happen after this board

Use this target board as the decision reference, then implement the shared system from the inside out.

1. Extract shared tokens Colors, spacing, radius, shadow, typography, dark/light behavior. This reduces drift before any visible redesign.
2. Align debt + decum Fastest product-family win with the least strategic ambiguity.
3. Preserve planner reading mode The hybrid report/planner reading view is strategically valuable and should stay alive in the lab.
