Cost of inaction

Every month the card balance stays near current levels, the plan loses flexibility twice: direct interest keeps accruing, and utilization stays high enough to limit cleaner refinancing options later.

Payoff logic

When a balance closes, its minimum should roll forward automatically. The interface should make that progression feel expected and mechanical, not like a separate planning exercise each time.

Guardrail

Any explored path that requires ongoing card reuse to survive should fail the test, even if it looks faster in nominal payoff months.

Action priorities
1. Stop the card rollover before the line resets higher

This is the highest-leverage move because it reduces both monthly interest and future option loss.

2. Point the next bonus to the 19.9% card, not the car loan

The tool should make allocation errors obvious when a lower-rate balance feels emotionally appealing but mathematically slower.

3. Move the LOC only if rate spread stays above 5 pts

Refinancing belongs here as a tactical branch, not as the main story. It helps only when the payment discipline remains intact after the move.
