Approved Tool Direction

Decum stays practical, but it speaks more like a plan than a calculator.

This prototype is tuned for withdrawal decisions that need explanation, not just output. It keeps the tool surface visible at all times, shows what changed versus a baseline, and uses calmer planning language so the user can bridge from scenario work into planner or report follow-through.
