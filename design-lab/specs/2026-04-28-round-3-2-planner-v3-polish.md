# Round 3.2 - Planner V3 Polish

Date: 2026-04-28  
Location: `design-lab/experiments/round-3-2-planner-v3-polish`

## Goal

Evolve Planner V3 with a lighter-touch polish pass instead of a redesign.

## Principles

Keep:

- simulator-first identity
- rail + tabs + cockpit
- dense workbench feel
- slightly nerdy / lab-like tone

Improve:

- cleaner typography
- better spacing
- better rail grouping / labels
- stronger longform drawer
- clearer report / guide handoff
- better light mode consistency

Avoid:

- glossy editorial treatment
- stacked page-card experience
- report shell with inputs attached

## What this round is testing

1. whether the planner can feel more coherent without losing its dev-mode soul
2. whether light mode can align better with the Product family
3. whether the longform drawer can become more useful without becoming luxury UI
4. whether report + guide handoff can be clearer inside the same planner shell

## Success criteria

- still feels recognizably like Planner V3
- light/dark feel closer to the other products
- rail and tabs are easier to parse
- report/guide/drawer relationship is more obvious
- overall polish improves without making the planner feel overdesigned
