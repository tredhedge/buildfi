Planner Bridge

The planner should feel like the place where tools turn into understanding.

This beta is not a production planner rebuild. It is an isolated attempt to combine the Product family’s control logic with the Reading family’s interpretation logic so the planner can become the real center of the portfolio.

Product side

Inputs, presets, compare logic, dark/light persistence, quick what-if testing.

Bridge role

Shared baseline, calmer explanation, chapter-like plan readout, visible next actions.

Reading side

Interpretive pacing, plan-at-a-glance framing, and a path toward report handoff.

What this beta is testing

1. Shared planner spine

Setup, baseline plan, explored alternative, and action guidance in one continuous shell.

2. Two views, one planner

Builder view emphasizes controls. Reading view emphasizes explanation. The underlying plan stays the same.

3. Report handoff logic

The planner should already teach the user how to read the future report instead of feeling like an unrelated tool.

4. Website can wait

If the planner bridge works, the website can follow it later. It does not need to lead.
